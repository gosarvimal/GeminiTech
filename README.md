# HTML Application Prompt Generator Pro 3.0

A React application built with TypeScript and Vite that allows users to describe an application, configure its inputs and outputs, and generate comprehensive, professional AI coding prompts.

## Features

- **01 · Goal**: Set application name, core problem statement & purpose, and intended audience.
- **02 · Inputs**: Configure up to 10 input fields with dynamic types (Text, Number, Date, GSTIN, Dropdown, Radio, File uploads, etc.), mandatory toggles, validation presets, and constraints (choices, min/max/step limits, file size limits).
- **03 · Outputs**: Configure up to 10 outputs (Tables, Invoices, CSV, Excel, PDF, Dashboards, Charts, JSON, etc.), optional AI integrations with provider/mode configurations, and reference file attachment handling.
- **04 · Behavior & Validation**: Configurable persistence, type validation, mandatory field highlighting, and custom business rules.
- **05 · Libraries**: CDN usage policy, preferred libraries list, and offline guidelines.
- **06 · Design**: Hex color pickers for primary and accent colors with bidirectional sync, visual styles, typography selection, and responsive toggles.
- **07 · Deliverables**: Deliverable checklist (standalone single-file, embedded assets, runnable, code comments, sample data, test cases).
- **Prompt Generator**: Instant validation, prompt compilation, clipboard copy, and `.txt` file export.
- **Persistence**: Drafts automatically persist in browser `localStorage`.

## Tech Stack

- React 18
- TypeScript
- Vite
